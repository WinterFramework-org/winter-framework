# Triage labels

| 스킬의 역할 | GitHub 라벨 | 의미 |
|---|---|---|
| needs-triage | needs-triage | 검토 필요 |
| needs-info | needs-info | 추가 정보 필요 |
| ready-for-agent | ready-to-implement | 요구사항이 구체화되어 에이전트가 구현 가능 |
| ready-for-human | needs-intervention | 사람의 개입이 필요한 작업 |
| wontfix | not-planned | 진행하지 않기로 결정 |

스킬이 역할 이름을 사용하면 대응하는 GitHub 라벨을 적용한다.
